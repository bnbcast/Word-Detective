# Word Detective

Ranks the words that give away AI-written text by comparing word frequencies against human answers, using Laplace smoothing. A statistics explainer built in the browser.

## What it does

- Compares AI vs human word frequencies from an embedded dataset
- Ranks the most "AI-giveaway" words with Laplace smoothing
- Exact / case-insensitive / stemmed matching modes
- Plain-language assumptions and interpretation

## Stack

JavaScript · Statistics · Data viz · React 19 · Vite 6

## Run locally

```sh
npm install
npm run dev
npm run build
```

## Deploy
